# História da tecnologia (site)

Site de página única sobre a história da tecnologia — do ábaco à
inteligência artificial. Começou como um layout genérico que eu tinha
feito pra treinar estrutura HTML, e fui transformando num site de
verdade: conteúdo real, tipografia e um CSS mais caprichado.

**Abrir:** https://luizassing.github.io/RepositorioPessoal/projetos/site/

## O que tem

- Cabeçalho com navegação por âncoras
- Introdução curta
- Linha do tempo com os principais marcos
- Seção "As eras da tecnologia" com um resumo de cada período
- Rodapé em colunas (sobre, navegação, contato)

## O que pratiquei aqui

- Estrutura semântica de HTML (`header`, `main`, `section`, `article`, `footer`)
- Layout com Flexbox
- Variáveis CSS, `clamp()` para tipografia fluida
- Layout responsivo com media queries
- Uma linha do tempo só com CSS (borda + pseudo-elementos)

## Rodar localmente

É só abrir o `index.html` no navegador. Sem build, sem dependências.
